# Stage Flow | UX mobile: editor por etapas reais (28/10/2026)

O editor do cantor agora guia em quatro etapas: identidade/fotos, apresentação, redes e publicação/contratação. O editor de músico usa cinco: visual/fotos, instrumentos, experiência, mídias e contratação/publicação. Quando a mesma pessoa é cantora e musicista, a etapa redundante de aparência/fotos é omitida; mantém-se uma identidade pública única.

A navegação mobile é acessível (etapa atual, barra de progresso e botões anterior/próxima), e as entradas não são desmontadas ao alternar etapas. Salvar verifica controles nativos e abre a etapa do campo inválido antes de destacar o problema. O desktop continua exibindo todas as seções. Nada é salvo automaticamente: salvar via RPCs já existentes; não foi feita nenhuma migração.

Limites: a inspeção visual real em iPhone/Android e a revisão com dispositivo físico ainda dependem de teste humano. A publicação continua manual, exclusivamente após autorização expressa do proprietário. Auto deploy permanece desativado.
